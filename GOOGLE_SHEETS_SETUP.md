# Подключение регистрации к Google Sheets

Форма отправляет данные по HTTPS в Google Apps Script. Скрипт может **добавлять** строки, но не предоставляет сайту функции чтения таблицы. Сама таблица остаётся закрытой; её ссылка не добавляется на сайт. Для отправки заявок с публичного сайта Apps Script Web App должен принимать запросы от всех посетителей, поэтому публичен только URL приёма заявок — не таблица и не её содержимое.

## 1. Создайте закрытую таблицу

1. Создайте Google Spreadsheet и лист `Registrations` (если листа нет, скрипт создаст его автоматически).
2. В настройках доступа оставьте режим **«Ограниченный доступ»**. Добавьте только тех администраторов, которым действительно нужно просматривать и удалять заявки; не включайте публикацию в интернете и не выдавайте доступ по ссылке.
3. Скопируйте ID таблицы из адреса между `/d/` и `/edit`.

## 2. Установите Apps Script

1. В таблице откройте **Расширения → Apps Script**.
2. Замените содержимое редактора кодом из `google-sheets-apps-script.gs` и сохраните проект.
3. В настройках проекта Apps Script откройте **Свойства скрипта** и добавьте свойство:
   - имя: `SPREADSHEET_ID`
   - значение: скопированный ID таблицы.

Скрипт проверяет поля на сервере, добавляет строку с датой и временем, не выводит содержимое таблицы и подавляет повторную запись при повторе того же запроса. Первая строка листа создаётся автоматически. Повторная отправка блокируется на срок хранения ключа идемпотентности (до 6 часов).

## 3. Разверните приём заявок

1. Нажмите **Развернуть → Новое развертывание** и выберите тип **Веб-приложение**.
2. Установите **Выполнять от имени: меня** — это позволяет скрипту записывать в таблицу без выдачи доступа заявителям.
3. В поле доступа выберите **Все** (или эквивалент «Anyone»). Это необходимо, чтобы посетители без Google-аккаунта могли зарегистрироваться. Такой URL разрешает отправку заявок, но код не содержит обработчика чтения таблицы. Не отправляйте URL таблицы и не предоставляйте доступ к самой таблице заявителям.
4. Завершите развертывание и скопируйте URL веб-приложения, оканчивающийся на `/exec`.

В `script.js` задайте скопированный URL как значение `REGISTRATION_ENDPOINT` в начале блока отправки формы. URL должен начинаться с `https://script.google.com/macros/s/` и оканчиваться на `/exec`. Опубликуйте обновлённый сайт на HTTPS-хостинге.

Если меняете код Apps Script после развертывания, создайте новую версию развертывания через **Управление развертываниями → Изменить → Новая версия**.

## 4. Проверьте и обслуживайте

1. Отправьте тестовую заявку и проверьте появление одной строки с семью указанными столбцами.
2. Удалите тестовую запись. Администратор может удалять заявки непосредственно в закрытой таблице.
3. Периодически проверяйте список редакторов и удаляйте доступ тех, кому он больше не нужен. Выдавайте минимальные права.

Форма не показывает заявки посетителям, не помещает их в URL и не печатает персональные данные в консоль или сообщения об ошибках. В Apps Script оставлена только общая обработка ошибки без записи пользовательских значений в журналы. Публичный URL приёма теоретически может получать нежелательные запросы; скрытое поле и проверка на сервере снижают простой спам, но для большого потока или повышенных требований к защите добавьте серверный rate limit/антибот-защиту с администратором или перенесите приём на защищённый backend. Не используйте эти данные для рекламы, рассылок или передачи третьим лицам без отдельного соответствующего согласия.
